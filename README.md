# EzBot Robotics Team Portfolio

Welcome to the EzBot Robotics Team portfolio website! This GitHub Pages site showcases our team's projects, achievements, and innovations in robotics.

## About This Site

This website is built using:
- HTML5
- CSS3
- JavaScript (ES6+)
- GitHub Pages for hosting

## Local Development

To run this site locally:

1. Clone the repository
2. Open `index.html` in your web browser
3. Or serve it using a local server:
   ```bash
   # Using Python 3
   python -m http.server 8000
   
   # Using Node.js (if you have live-server installed)
   npx live-server
   ```

## Deployment

This site is automatically deployed to GitHub Pages when changes are pushed to the main branch.

## Project Structure

```
├── index.html          # Main homepage
├── style.css          # Main stylesheet
├── script.js          # JavaScript functionality

└── assets/            # Images and other assets (to be added)
```

## Features

- Responsive design that works on all devices
- Smooth scrolling navigation
- Modern CSS with animations
- Clean, professional layout
- Optimized for GitHub Pages

## Customization

To customize this site for your robotics team:

1. Update the team name in `index.html`
2. Modify colors and styling in `style.css`
3. Add your team's projects and member information
4. Include your team's logo and images in an `assets/` folder
