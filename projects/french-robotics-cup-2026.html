French Robotics Cup 2026

Next-generation robotics with advanced vision and positioning systems

About the Project

The French Robotics Cup continues to be one of the most prestigious robotics competitions in France, bringing together the best teams from universities and engineering schools across the country. For 2026, we're pushing the boundaries of autonomous robotics with cutting-edge technologies including advanced computer vision, precision positioning systems, and enhanced perception capabilities.

Revolutionary Vision System

Our 2026 robot features a comprehensive vision system that sets it apart from previous generations. We're implementing multiple layers of visual perception for unparalleled game awareness:

  • Onboard Robot Vision: Integrated computer vision system for real-time game object recognition and classification
  • External Camera with ArUco Tracking: Overhead camera system for precise robot positioning and enemy robot tracking using ArUco markers
  • Multi-sensor Fusion: Combining multiple vision sources for robust and redundant perception
  • Real-time Object Detection: Advanced AI algorithms for identifying and tracking game pieces, obstacles, and dynamic elements
  • Strategic Vision Processing: Vision-based decision making for optimal game strategy and movement planning

Precision Positioning with LIDAR

Achieving absolute positioning accuracy is crucial for competitive robotics. Our 2026 robot features an innovative LIDAR-based positioning system:

  • LIDAR Triangulation/Trilateration: Using distance measurements to four fixed columns on the play table for absolute positioning
  • Sub-centimeter Accuracy: Precision positioning system for exact movement and placement operations
  • Real-time Localization: Continuous position updates for dynamic path correction and strategic repositioning
  • Redundant Positioning: Multiple positioning methods ensuring reliability even if individual sensors fail
  • Environmental Mapping: Creating detailed maps of the play area for optimal navigation and strategy

Enhanced Drive System

Building on our successful 3-wheeled holonomic design from 2025, we're upgrading the motor technology while maintaining the proven configuration:

  • 3-Wheeled Holonomic Configuration: Proven design for superior maneuverability and obstacle navigation
  • Motor Technology Upgrade: Transitioning from stepper motors to closed-loop stepper motors for improved precision and efficiency
  • Enhanced Torque and Speed: Closed-loop steppers provide better torque characteristics and speed control
  • Improved Reliability: Closed-loop feedback prevents missed steps and ensures consistent performance
  • Precision Movement: Enhanced motor control for exact positioning required by LIDAR navigation system

Integrated Technology Ecosystem

Our 2026 robot represents a complete technological ecosystem where all systems work in harmony:

  • Vision-LIDAR Fusion: Combining visual and distance data for comprehensive environmental understanding
  • AI-Driven Decision Making: Machine learning algorithms processing multiple sensor inputs for optimal strategy
  • Real-time Processing: High-performance computing for simultaneous multi-sensor data processing
  • Adaptive Behavior: Robot behavior that adapts based on game state, opponent actions, and environmental conditions
  • Robust Communication: Reliable data exchange between onboard systems and external monitoring
